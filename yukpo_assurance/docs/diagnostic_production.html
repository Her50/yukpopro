Déclarations en rafale (plusieurs en 72h dans même compagnie) Retourne JSON : {{ "reseau_detecte": true/false, "score_reseau": 0-100, "acteurs_suspects": [], "pattern_identifie": "", "recommandation": "bloquer|surveiller|passer" }}""" reponse = await ia_client.appeler( prompt=prompt, mode=ModeIA.PRECISION, json_attendu=True ) return reponse.as_json()
